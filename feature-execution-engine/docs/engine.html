engine.options_strategy.compute_otm_strike(underlying_price, direction, delta_target=0.3)[source]

Compute an out-of-the-money strike price for a given delta target.

For 0DTE options, delta changes rapidly with small moneyness moves. This approximates the OTM distance as roughly 2 % per 1.0 delta (e.g. 30-delta → ~0.6 % OTM), which produces strikes that actually exist in the chain.

Parameters:

  • underlying_price (float) – Current price of the underlying asset.

  • direction (Direction) – CALL or PUT direction.

  • delta_target (float) – Target delta for the option (default 0.30).

Returns:

The computed OTM strike price rounded to the nearest $1.00 increment.

Return type:

float

static check_consensus(briefing_direction, market_news_polarity, min_sources=2)[source]

Check whether multiple data sources agree on market direction.

None values are treated as “this source is unavailable” — e.g. a degraded Atlas briefing yields None for macro_sentiment and must not count toward consensus.

Parameters:

  • briefing_direction (float | None) – Sentiment polarity from the briefing, or None when briefing quality is not FULL.

  • market_news_polarity (float | None) – Average polarity from market news, or None when no news was fetched.

  • min_sources (int) – Minimum number of sources with non-trivial signal.

Returns:

Tuple of (consensus_reached, average_direction).

Return type:

tuple[bool, float]
